# Skill: Closed-Loop Learning (Client Framework)

This skill handles the client-side extraction of lessons from test failures or agent bugs (generated by `tester.py`) and uploads them to the centralized backend (Firebase `incoming_lessons` table).

## Processing Bugs into Lessons

To process all bugs in a given lab directory (e.g., created by `tester.py`):

```bash
python3 .agents/skills/closed-loop-learning/scripts/bug_to_lesson_processor.py --scan-dir /path/to/lab/bugs
```

This script reads all `bug_*.json` files that haven't been processed, uses Vertex AI to extract a generalized lesson, and pushes it to the centralized Firebase backend for human curation in the Admin Portal.

_(Note: The Admin Portal and Cloud Run MCP RAG Server are managed in a separate backend repository)._
